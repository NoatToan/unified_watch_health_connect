# Watch model catalog

Generated by `scripts/gen_watch_catalog.py`. Product images are © their manufacturers and are bundled only to help users recognise their own device (see D-801 in DECISIONS.md).

Regexes are anchored Java/Kotlin patterns intended for case-insensitive matching against the advertised BLE name after NFD diacritic folding (as WatchModelMatcher does); patterns still accept 'ē'/'í' for unnormalised input. Within each vendor, more specific entries come before broader ones; '<vendor>_generic' entries are last-resort fallbacks. Primary evidence: Gadgetbridge master (codeberg.org/Freeyourgadget/Gadgetbridge) DeviceCoordinator.getSupportedDeviceName() patterns, fetched 2026-11-08. Garmin advertises the bare model name (Gadgetbridge uses ASCII 'fenix'/'vívoactive'); newer Garmin models append ' - 47mm'. Huawei/Honor append '-XXX' (hex) to an upper-case name; WATCH Ultimate 2 and GT Runner 2 omit the HUAWEI prefix. Zepp OS devices advertise the exact model name with an optional ' XXXX'/'-XXXX' MAC suffix; some newer ones drop the 'Amazfit ' prefix. Xiaomi Smart Band 8/9/10 (and 7 Pro) use Xiaomi's own protocol, not Huami; only Mi Band 5/6 and Xiaomi Smart Band 7 are Huami/Zepp. COROS advertises 'COROS <MODEL> <6 hex of MAC>' (PACE 3 confirmed by Gadgetbridge and SySS); PACE 4/4 Pro/APEX 4/NOMAD/VERTIX 2S patterns are inferred (bleNameConfidence=low). 'Amazfit GTR 4 Mini' is not a product found in any source; it is mapped to Amazfit GTR Mini on request. Images: manufacturer CDNs only (res.garmin.com 'cf-lg' = centre-front large; consumer.huawei.com '/dam/content/dam/...' list images, transparent PNG; honor.com; Amazfit's own Shopify stores us.amazfit.com/www.amazfit.com; staticcn.coros.com; i02.appmifile.com; polar.com). Every non-null imageUrl returned HTTP 200 with an image/* content type via 'curl -sIL -A Mozilla/5.0' at generation time; Shopify file names can change when the store updates the product. 3D: none of Garmin, Huawei, Honor, Amazfit/Zepp, Xiaomi, COROS or Polar publish official GLB/GLTF/USDZ models or 360-degree spin sets on their product pages (checked page markup; only third-party 3D marketplaces exist), so model3dUrl is null everywhere.
